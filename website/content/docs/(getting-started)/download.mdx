Scripting Nodes needs Blender 5.0 or newer.

## Install

<Steps>
<Step>

### Download

Use the button above to get the latest `.zip`. Older versions are on [GitHub releases](https://github.com/joshuaknauber/scripting_nodes/releases).

</Step>
<Step>

### Install from disk

In Blender, open **Edit → Preferences → Get Extensions**, click the dropdown in the top right and choose **Install from Disk…**, then pick the downloaded `.zip`.

</Step>
<Step>

### Open the editor

Switch any area to the **Scripting Node Editor**. That's where your node trees live.

</Step>
</Steps>

## Update

Install the new `.zip` the same way. Your node trees are saved in your `.blend` files, so they're not affected.
