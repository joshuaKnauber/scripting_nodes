title: Your first add-on
description: Build a node graph that prints a message.
---

This page walks through the smallest useful graph: a button that prints a message to the console.

<Steps>
<Step>

### Create a node tree

In the Scripting Node Editor, click **New** to create a node tree.

</Step>
<Step>

### Add the nodes

Add a **Trigger** node (Logic) and a **Print** node (Program), then connect the Trigger's **Logic** output to the Print's **Program** input. Type a message into the **Text** field.

![A Trigger node connected to a Print node](/screenshots/first-addon.png)

</Step>
<Step>

### Run it

Click **Trigger** on the node. The message shows up in Blender's system console.

</Step>
</Steps>

<Callout>
  The graph recompiles as you edit it, so changes take effect without reloading anything.
</Callout>
