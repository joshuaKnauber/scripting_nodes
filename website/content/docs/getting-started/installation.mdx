---
title: Installation
description: Install Scripting Nodes as a Blender extension.
---

Scripting Nodes targets Blender 5.0 and works with Blender 4.3 and newer.

<Steps>
<Step>

### Download

Grab the latest `.zip` from the [GitHub releases](https://github.com/joshuaknauber/scripting_nodes/releases).

</Step>
<Step>

### Install from disk

In Blender, open **Edit → Preferences → Get Extensions**, click the dropdown in the top right and choose **Install from Disk…**, then pick the downloaded `.zip`.

</Step>
<Step>

### Open the editor

Switch any area to the **Scripting Node Editor**. That's where your node trees live.

</Step>
</Steps>
