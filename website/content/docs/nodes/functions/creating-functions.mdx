A function is a node tree with inputs and outputs, like a node group in Geometry Nodes. It becomes a Python function in your add-on, and **Group** nodes call it from other trees.

![A tree calling three functions: Greet from an operator, Header and Double inside a panel](/screenshots/functions-call.webp)

![The panel this tree draws in the 3D viewport sidebar](/screenshots/functions-panel.webp)

## Creating a function

- **Ctrl+G** turns the selected nodes into a function. Links that crossed the selection become its inputs and outputs, and the selection is replaced by a Group node calling it.
- **Ctrl+Alt+G** puts the nodes of the selected Group nodes back.
- **Tab** enters the selected Group node, **Ctrl+Tab** goes back up.
- **Add > Groups** has Group Input, Group Output, an empty Group node (its **New** button creates a function) and one entry per function.
- **+ › Function** in the sidebar's **Files** list creates one in the selected folder. New functions go next to the tree they're made from.

Functions are listed in **Files** with the other trees. Functions no Group node calls are marked *unused*; select one to see the nodes calling it. Deleting a function that's still used asks first, and the nodes calling it then ask for another one.
