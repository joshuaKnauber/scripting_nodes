---
title: Math
description: Numbers, vectors and conversions.
icon: Calculator
---

| Node | |
| --- | --- |
| **Math** | Add, subtract, multiply, divide, power and modulo of two numbers |
| **Clamp** | Limits a value to a range |
| **Map Range** | Maps a value from one range to another |
| **Round Float** | Rounds to a number of decimals: up, down or to the nearest |
| **Vector Math** | Add, subtract, multiply, divide, cross and dot product, normalize, length and distance of vectors |
| **Combine Vector** / **Separate Vector** | A vector from X, Y, Z (and W) and back |
| **Convert Angle** | Degrees to radians and back. Blender stores angles in radians (a rotation of 90° is 1.5708) |
| **Random Value** | A random float or integer between **Min** and **Max**, a boolean, a vector or a color. It's new every time the value is used |

Math and Clamp give a **Float Result** and an **Integer Result** (the float cut off to a whole number).

For anything else, a [Python Expression](/docs/nodes/python/blender-api#python-expression) does it in one line: `math.sqrt(value)`, `max(a, b)`.
