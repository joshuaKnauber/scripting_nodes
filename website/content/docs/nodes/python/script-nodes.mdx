Python from a text block or a `.py` file, see [Scripts](/docs/concepts/scripts) for the details.

| | Use it to | Sockets |
| --- | --- | --- |
| **Addon Data › Scripts** | Make a script part of the add-on: its classes are registered, its `register()` / `unregister()` called | |
| **Script Function** | Call a function of one of those scripts | From the function's signature: parameters are inputs, return values outputs |
| **Inline Script** | Run a few lines where the node is in a flow: in an operator, a panel, a timer | Flow in and out; names the code doesn't define become inputs, variables it assigns can be outputs |

For one line, **Python Expression** and **Python Statement** are quicker: see [Using Blender's API](/docs/nodes/python/blender-api).
