An **Operator** node (**Add › Logic**) is an action of your add-on: what a [Button](/docs/nodes/interface/fields-and-buttons), a [Shortcut](/docs/nodes/operators/shortcuts) or [Run Operator](/docs/nodes/operators/running-operators) runs. Its **Execute** flow is what it does. The play button on the node runs it.

- **Label** is the operator's name in the interface and in the operator search (F3). Its Python name (`my_addon.label`) comes from it.
- **Is Available** turns the operator off: buttons running it are grayed out, shortcuts do nothing. Connect a condition, e.g. whether an object is selected.
- Its [properties](/docs/properties/properties#operator-and-preferences-properties) are listed in the sidebar's **Node** tab and are outputs of the node in its flows.

## Settings

**Settings** on the node opens the rest:

- **Description**: the tooltip.
- **Invoke Type**: what happens when it's started from the interface (a button, a menu, a shortcut):
  - **Execute** runs right away.
  - **Properties Dialog**, **Properties Popup** and **Confirm** ask first, see [Popups and dialogs](/docs/nodes/operators/popups).
  - **Invoke** gives an **Invoke** flow (with the **Event** that started it) that runs before **Execute**.
  - **File Browser** opens Blender's file browser first, see below.
  - **Modal** keeps the operator running, see [Modal operators](/docs/nodes/operators/modal-operators).
- **Register** shows it in the operator search and the **Adjust Last Operation** panel, **Undo** adds an undo step. **Depends on Cursor** makes it wait for a click in the editor when it's started from a menu or the search, for operators that use the mouse position. The other options are Blender's `bl_options`.

## Opening and saving files

With **Invoke Type** **File Browser**, the operator opens the file browser and runs **Execute** with what was picked: **File Path**, **File Paths** or **Folder**, depending on **Pick**:

- **Open File** / **Open Files**: one or several existing files. **Filter** (`*.png;*.jpg`) only shows those.
- **Save File**: a file name to save to; Blender warns before overwriting.
- **Folder**: a folder.

A **File Handler** node (**Add › Logic**) runs such an operator when files are dragged onto Blender: set the **Extensions** (`.csv;.txt`) and the editor they're dropped in. The dropped file is the operator's **File Path**, without the browser opening.

## Ending early

**Return** (**Add › Logic › Modal**) ends the operator's flow where it is: **Finish** keeps what it did, **Cancel** acts as if it didn't run (no undo step). Without it, the operator finishes after its flow.

## Reports

A **Report** node shows a message in the status bar and the Info editor: **Info**, **Warning** or **Error** (errors also show a popup). Use it in an operator's flows, or in a function called from one. Elsewhere (a panel, a handler, a timer) there's nothing to report to, and the message is printed instead.
