**Repeat** runs the nodes on its **Loop** output a number of **Times**, then continues at **After**. Use it when you know how often something should happen: add five cubes, try three times, count down from ten.

![Repeat with a Switch on the Index: run 3 goes to Next Item, run 7 to Stop Loop, every other run prints its index, and Print "Done" runs after the loop](/screenshots/flow-loops.webp)

## Repeat

| Socket | |
| --- | --- |
| **Times** (input) | How often **Loop** runs. 3 by default; 0 or less runs it never |
| **Loop** | Runs once per repetition |
| **Index** | The number of the current run, counting from 0: 0, 1, 2 for **Times** 3 |
| **After** | Runs once, when the loop is done |

**Index** only exists inside the loop. A node after **After** that uses it shows an error.

To run nodes once for every item of a list or a Blender collection (all objects, the selected objects, a mesh's vertices), use [For Each (List)](/docs/nodes/data/lists#for-each-list) instead. In a panel, [Draw For Each](/docs/nodes/interface/lists#draw-for-each) draws a row per item.

To keep a value from one run to the next, such as a total, store it in a [Local Variable](/docs/nodes/variables/local-variables) before the loop and change it inside.

## Stopping early

**Break / Continue** (**Add › Flow**) changes what a loop does next. Pick the action in the dropdown on the node; its title shows the choice.

- **Stop Loop** leaves the loop right away and continues at **After**.
- **Next Item** skips the rest of this run and goes on with the next one.

It has no output: nothing after it runs in this run. Put it after an **If/Else** or a **Switch**, so it only stops or skips for some runs, as in the screenshot.

It works in **Repeat** and **For Each (List)** loops. Outside of a loop, or inside a [function](/docs/nodes/functions) called from a loop, it shows the error "Only works inside a loop".

<Accordion title="What it generates">

The tree in the screenshot becomes a Python `for` loop. **Index** is only given a name when something uses it (`_` otherwise):

```python
for index in range(10):
    value = str(index)
    if value == "3":
        continue
    elif value == "7":
        break
    print(str(index))
print("Done")
```

**Stop Loop** is Python's `break`, **Next Item** is `continue`.
