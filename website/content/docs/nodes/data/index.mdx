The Data nodes give values to other nodes: a number, a text, a list, whether two values are equal. They're in **Add › Data**, with the submenus **Boolean**, **Input**, **List** and **String**.

## Value nodes

Most Data nodes have no flow sockets (the diamond-shaped ones), only data inputs and outputs. These value nodes don't run at a point in a flow. They compute their result where something uses it: connect a **Float** to a **Print**, and the number is written right into the Print's code.

Two things follow from this:

- A value node computes again for every input it's connected to. A **Random Value** connected to two inputs gives two different numbers, and a **Current Time** connected twice reads the clock twice.
- A value node can't remember anything. **Create List** makes a new, empty list every time it's used, so a **List Append** that adds to it adds to a list nobody sees again. To build up a list or a total, store it in a [variable](/docs/concepts/variables) first. [Lists](/docs/nodes/data/lists) shows how.

The nodes that change a list (**List Append**, **List Sort**, ...) and **For Each (List)** do have flow sockets: they run in a flow, like a **Print**.

## Socket types

The color of a socket shows the type of value it carries.

| Type | Holds |
| --- | --- |
| **Data** | Any value. Gray, no field: an unconnected Data input is `None` |
| **Blender Data** | Blender data: an object, a scene, a material, ... |
| **String** | Text |
| **Boolean** | True or False |
| **Float** | A decimal number |
| **Integer** | A whole number |
| **Vector** | 2 to 4 numbers, like a location |
| **Color** | 3 (RGB) or 4 (RGBA) numbers from 0 to 1 |
| **List** | A list of values (square socket). Blender collections like `bpy.data.objects` connect to it too |
| **Icon** | A built-in icon or a custom one |

You can connect most types to each other. The value is converted on the way:

| From → to | Result |
| --- | --- |
| Anything → **String** | The value as text (`str()`). Blender data gives its name: an object becomes `"Cube"` |
| Anything → **Boolean** | `bool()`: 0, empty text, empty lists and `None` are False, everything else True |
| **Integer** → **Float** | The same number |
| **Float** → **Integer** | Cut off to a whole number: 2.9 becomes 2 |
| **String** → **Float** / **Integer** | The number in the text, 0 if the text isn't a number |
| **Float** / **Integer** → **Vector** / **Color** | The number in every component: 0.5 becomes `(0.5, 0.5, 0.5)` |
| **Vector** ↔ **Color** | The first three components; a color gets alpha 1 |
| **Vector** / **Color** / **List** → **Float** / **Integer** | The first component |
| Single value → **List** | A list with that one value; a text becomes a list of its characters |
| Anything → **Data** | Unchanged |

Some connections can't work and show an error on the node: Blender data into a number, vector or color, or a plain value into a Blender Data input.
