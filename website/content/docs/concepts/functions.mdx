A function is a node tree with inputs and outputs, like a node group in Geometry Nodes. It becomes a Python function in your add-on, and **Group** nodes call it from other trees.

![A tree calling three functions: Greet from an operator, Header and Double inside a panel](/screenshots/functions-call.png)

![The panel this tree draws in the 3D viewport sidebar](/screenshots/functions-panel.png)

## Creating a function

- **Ctrl+G** turns the selected nodes into a function. Links that crossed the selection become its inputs and outputs, and the selection is replaced by a Group node calling it.
- **Ctrl+Alt+G** puts the nodes of the selected Group nodes back.
- **Tab** enters the selected Group node, **Ctrl+Tab** goes back up.
- **Add > Groups** has Group Input, Group Output, an empty Group node (its **New** button creates a function) and one entry per function.

![After Ctrl+G on Combine Strings and Print: the new function, with Group Input / Output for the links that crossed the selection](/screenshots/functions-make-group.png)

## Inputs and outputs

Edit them in the sidebar's **Group** tab: add, remove, rename, reorder, set a type and a default value. You can also drag a link onto the empty socket of Group Input or Group Output. Renaming or reordering keeps the links of every Group node calling the function.

Data inputs are the function's parameters, data outputs its return values.

![Inside the Greet function, with its inputs and outputs in the sidebar's Group tab](/screenshots/functions-interface.png)

## Flow

The flow sockets of a function decide how it is called:

| Inputs / outputs | Called as |
| --- | --- |
| No flow sockets | A value. Use its outputs anywhere, like a Math node. |
| A **Program** flow input (and output) | A step in a flow. The function runs from Group Input's flow, and the caller continues at the flow output. |
| An **Interface** flow input (and output) | UI drawn into the panel, menu or popup the Group node is in. |

The return values are whatever is connected to Group Output when the flow reaches it, so connecting a branch (e.g. If/Else **Then**) to Group Output returns early. A function has at most one flow input and one flow output.

## Generated code

```python
def greet_1a2b3c4d5e(name, *, self=None, context=None, layout=None, event=None):
    context = context or bpy.context
    sn_print(''.join(['Hello, ', name]))
    return ''.join(['Hello, ', name])
```

The caller passes on `self`, `context` and `event` where they exist (inside an operator, a panel, …), and `layout` to interface functions.
