## Node trees

Each Scripting Nodes tree is one Python module of your add-on. All trees in a file together form the add-on.

## Sockets

There are two kinds of sockets:

- **Flow sockets** (diamond-shaped) define the order things run in. A Trigger's **Logic** output runs whatever is connected to it, one node after another.
- **Data sockets** (round) pass values such as text, numbers or objects between nodes.

## Code generation

Every node contributes a piece of Python. When you change the graph, Scripting Nodes regenerates the affected code and reloads it in place, so you can test while you build.
