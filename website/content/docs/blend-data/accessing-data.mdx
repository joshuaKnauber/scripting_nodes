Everything in a Blender file can be reached by following a path: the active object, its modifiers, the width of its Bevel modifier. The **Blender Data** node follows one such path and outputs what it finds.

![Blender Data nodes reading the active object's Bevel width and its mesh's vertex count](/screenshots/blend-data.webp)

## The Blender Data node

Add it from **Add › Data › Blender Data**. The menu has ready-made entries for common starting points (Active Object, Selected Objects, Scene, View Layer, All Objects, Blend File, ...), which add the node already set up.

A path has a **start** and the steps after it:

- **Context**: what's current where your code runs, e.g. `active_object`, `scene`, `selected_objects`.
- **Blend File**: everything in the file, e.g. `objects`, `materials`, `scenes`.
- **Input**: the data connected to the node's **Data** input. Use it to continue from another node, e.g. the `modifiers` of an object.

The node shows its path as a button, e.g. **Active Object › Modifiers[] › Width**; click it to pick the start and the path in the [browser](#browsing-the-open-file). The header shows where the path ends, e.g. **Modifiers[] › Width**.

## Typed outputs

The output has the type of what the path ends at: **Width** is a Float, **Use Simplify** a Boolean, **Active Object** an Object. Connected nodes know the type too, so a second Blender Data node that starts at its Data input only offers the properties of an Object.

Some paths can hold different types: `active_object.data` is a mesh for a mesh object but a camera for a camera. Pick the type with the arrow next to the output (**Data ⌄ Mesh**) to continue with mesh properties like `vertices`.

Lists (collections, drawn with a square socket) work with the **Collection** nodes (Length, Get Item, For Each, ...).

## Items of a list

`[]` in a path picks one item of a list. Each `[]` adds an input, and the icon next to it chooses how the item is picked:

- **Index**: by position, `0` is the first, `-1` the last.
- **Name**: by name, e.g. the modifier called "Bevel".
- **Active**: the list's active item, where the list has one (e.g. `material_slots`).

## Browsing the open file

The path button on the node opens the **Blender Data** browser. It shows the data of the open file, the real objects, modifiers and values, in columns like a file browser: one column per step of the path, starting where the node's path is right now.

- Start at **Context** (the active object, the scene, ...), **Blend File** (all objects, materials, ...) or the node's **Data Input**, and click entries to go into them. From the Data input the browser shows the data of the connected Blender Data node, or what its type has. The steps above the columns go back. Entries with an arrow can be opened (objects, modifiers, lists); the others are values, shown with what they are right now. Empty entries and read-only values are hidden until you tick **Empty and Internal**.
- **Search** finds data by name: first in the data below where you are (`bevel width` from the active object finds its Bevel modifier's width), then every path from the start.
- **Use Path** (or Enter) sets the node's path to where you are. A node that starts at its Data input keeps that input when the path continues from it.

When the data isn't there right now (no active object, for example), a column lists what the type has instead, without values.

## Generated code

The node becomes the path itself, written with the `context` the surrounding function gets (or `bpy.context` where there is none):

```python
def execute(self, context):
    print(str(context.active_object.modifiers['Bevel'].width))
    print(str(len(context.active_object.data.vertices)))
```

To change a value instead of reading it, use **Set Property** with a path, see [Data paths](/docs/blend-data/data-paths).

## Calling Blender's functions

Some things aren't values you read or set but functions you call: adding a modifier, creating an object, linking it to a collection, selecting it. The **Blender Function** node (**Add › Data › Blender Data**) calls one. Its path leads to the data the function belongs to, then you pick the function in the browser, where functions are listed with `()` after the data: **Active Object › Modifiers › new()**.

- The function's parameters become inputs, with Blender's defaults. Optional ones are only written to the code when you change or connect them.
- What it returns becomes outputs with their real types: `new()` gives the new **Modifier**, so you can set its properties next.
- Data a function needs (the object for `link()`) has to be connected.
- The menu has entries for common calls: **Add Modifier**, **New Object**, **Link Object**, **Select Object**.

```python
def execute(self, context):
    modifier = context.active_object.modifiers.new(name='Bevel', type='BEVEL')
    modifier.width = 0.2
```
