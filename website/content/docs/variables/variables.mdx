---
title: Variables
description: Store values while your add-on runs.
icon: Variable
---

Variables keep a value while Blender runs, unlike [properties](/docs/properties/properties), which are saved with the file and can be shown in the interface.

- A **Global Variable** exists once for the whole add-on. Give the node a label (it names the variable) and an **Initial Value**. It's set to it again when the add-on is enabled or rebuilt.
- A **Local Variable** exists in the rest of the flow it's in, e.g. a total counted up in a loop.

**Get Variable** reads a variable, **Set Variable** changes it: pick the variable on the node. Global variables can be used from any tree, local ones only in their own.

Set Variable has three operations:

- **Set**: a new value.
- **Change By**: adds the **Amount** to the value: numbers count up (or down with a negative amount), text and lists get it added to their end.
- **Toggle**: switches a boolean between True and False.
