---
title: Introduction
description: Build Blender add-ons visually with nodes.
---

Scripting Nodes is a Blender add-on for building Blender add-ons. You connect nodes in a node editor, and Scripting Nodes turns the graph into Python that registers as a regular add-on, with operators, panels, properties and everything else.
